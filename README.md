# AI Chat Hub

Веб-приложение для работы с большими языковыми моделями: чат с несколькими LLM-провайдерами, RAG по собственным документам, интеграция инструментов через MCP, AI-агент, планировщик задач и Telegram-бот поддержки. Готово к деплою на VPS в Docker.

**Стек:** Python, FastAPI, SQLite, Docker, Docker Compose, Nginx, aiogram.

## Возможности

**Чат с LLM.** Веб-интерфейс для общения с моделями через OpenAI-совместимый API (RouterAI), с переключением провайдеров и моделей под тип задачи. Поддержка потоковых ответов (SSE).

**RAG (ответы по документам).** Полный пайплайн поиска по своей базе знаний: две стратегии чанкинга (фиксированное окно и структурное по заголовкам), эмбеддинги через OpenAI-совместимый эндпоинт, индекс на SQLite, гибридный поиск (семантика + точные вхождения ключей), реранкинг и фильтрация по порогу релевантности, ответы с разделами «Источники» и «Цитаты» из реально найденных фрагментов, защита от галлюцинаций (при низкой уверенности модель отвечает «Не знаю»).

**MCP (Model Context Protocol).** Собственный stdio-клиент и набор серверов-инструментов: файлы, git, tech-radar (поиск релизов на GitHub, суммаризация, сохранение), планировщик, поддержка. Поддержка сторонних MCP-процессов.

**AI-агент.** Агент с вызовом инструментов и пошаговым выполнением задач.

**Планировщик.** Периодический запуск задач с уведомлениями через webhook.

**Telegram-бот поддержки.** Бот на aiogram: AI-ответы, эскалация на оператора, тикет-система с админ-панелью.

**Деплой.** Docker Compose, Nginx с rate-limiting, развертывание на VPS, опциональный HTTPS через Caddy.

## Архитектура

```
app/        ядро: FastAPI, провайдеры LLM, RAG, агент, MCP-клиент, планировщик
bot/        Telegram-бот поддержки (aiogram) + тикеты
scripts/    MCP-серверы, сборка RAG-индекса, AI-ревью PR
data/       корпус документов для RAG, наборы тестовых вопросов
tests/      автотесты (unittest)
static/     фронтенд чата
```

## Быстрый старт (локально)

```bash
git clone https://github.com/1nv1ddd/challenge
cd challenge
cp .env.example .env        # заполнить ROUTERAI_API_KEY
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload   # http://localhost:8000
```

RAG-индекс собирается автоматически при старте (первый запуск 1-3 минуты). Ручная сборка: `python scripts/build_rag_index.py`.

## Деплой на VPS (Docker)

```bash
cp .env.example .env   # заполнить ключи
docker compose up -d --build
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

## О проекте

Проект вырос из AI Advent Challenge (35 ежедневных заданий по практической работе с AI): от базового чата с LLM до RAG, MCP, агента и продакшн-деплоя.
