**Задача:** Добавь эндпоинт GET /api/scheduler/jobs, отдающий список задач планировщика.

---

```python
from fastapi import APIRouter, HTTPException
from .scheduler_store import list_jobs  # Импортируем функцию из scheduler_store.py

router = APIRouter(prefix="/api/scheduler", tags=["scheduler"])

@router.get("/jobs")
async def get_scheduler_jobs() -> list[dict]:
    jobs = list_jobs()
    if not jobs:
        raise HTTPException(status_code=404, detail="Задачи планировщика не найдены.")
    return jobs
```
