**Задача:** Напиши тест на HTTP-слой: POST /api/branches с телом без checkpoint_id должен вернуть 400 с непустым русским detail. pytest в проекте НЕ установлен — используй unittest + fastapi.testclient.

---

```python
import unittest
from fastapi.testclient import TestClient
from app.main import app  # Импортируем объект приложения из основного модуля проекта

class TestHubAPI(unittest.TestCase):
    def test_create_branch_without_checkpoint_id(self):
        client = TestClient(app)
        
        response = client.post("/api/branches", json={})
        
        self.assertEqual(response.status_code, 400)
        self.assertIn("Нужно поле checkpoint_id.", response.json()['detail'])
```

Этот тест проверяет HTTP-ответ на POST-запрос к `/api/branches` без поля `checkpoint_id`. Он использует встроенного клиента FastAPI для выполнения запроса и проверяет, что ответ содержит статус 400 Bad Request и ожидаемое сообщение об ошибке.
